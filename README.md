# Исследование прошивки и интерфейса Canaan Avalon

**Автор:** Anton Vinogradov

## О проекте

Данный проект посвящен изысканиям, разборке и анализу работы прошивки и интерфейса устройств Canaan Avalon. Целью является глубокое понимание внутреннего устройства, протоколов обмена данными и возможностей кастомизации.

## Структура проекта

Проект организован в виде нескольких тематических каталогов для удобства навигации и использования.

### `ALINK`

В этом каталоге содержатся материалы, связанные с анализом протокола обмена.

*   **Логи:** Дампы данных, полученные с помощью логического анализатора.
*   **Перехваченные пакеты:** Захваченный трафик между компонентами устройства.
*   **`ava-11-12`:** Каталог с рабочим примером кода, который демонстрирует получение данных с чипов (температура, вольтаж) и их преобразование в читаемый формат.

### `APPS`

Здесь находятся вспомогательные утилиты и программы, написанные для помощи в анализе прошивки.

### `BIN`

Каталог содержит бинарные файлы прошивок (целиком и по частям), которые являются основным объектом исследования.

### `DOCs`

Набор заметок, документации и другой полезной информации, собранной в процессе работы над проектом.

### `LOGS`

Коллекция логов работы устройства в различных режимах, которые могут быть полезны для понимания его поведения.

### `REVERS`

Ключевой каталог с результатами реверс-инженеринга.

*   Результаты анализа дампа прошивки и её отдельных компонентов.
*   **`FW-Pages`:** Содержит веб-страницы, извлеченные напрямую из прошивки. Это помогает понять, как устроен веб-интерфейс устройства и как он взаимодействует с бэкендом.
